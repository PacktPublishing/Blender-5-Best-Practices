# Blender 5 Best Practices

This is the code repository for [Blender 5 Best Practices](https://www.packtpub.com), published by Packt.

**Build scalable, production-ready 3D workflows with Blender 5**

## About the book

*Blender 5 Best Practices* covers the habits that separate a beginner from a professional across the whole Blender pipeline: modeling, sculpting, materials, lighting, animation, physics, Geometry Nodes, project organization, exporting, and Python automation. Short hands-on examples and mini projects run through every chapter.

## What is in this repository

Only Chapter 13 uses code. The other chapters have no starter files, because you build each example yourself as you go.

| Chapter | Folder | Contents |
| --- | --- | --- |
| 13: Blender Automation and Advanced Tips with Python Scripting | [Chapter13](Chapter13) | Every script from the chapter, plus the two add-ons packaged as Blender extensions |

See [Chapter13/README.md](Chapter13/README.md) for a file-by-file guide.

## Software requirements

- Blender 5.1 or later (the extension manifests set `blender_version_min = "5.1.0"`)
- No Python installation is needed. Every script runs inside Blender's own Python, from the Text Editor or the Python Console in the Scripting workspace.

## Usage note

You are free to use and modify this code for personal learning and noncommercial projects. Use the scripts as a practical starting point: modify them, extend them, and turn them into a toolkit of your own.
